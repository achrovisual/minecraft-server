# Obsidian

> A simple, reliable, and lightweight way to run a modded Minecraft (Fabric) server in Docker.

## Description

**Obsidian** is a streamlined Minecraft server container designed to get your modded Fabric server up and running quickly. It removes the usual headaches of server hosting, such as manually downloading files or dealing with broken storage mounts, by automatically setting up the environment for you. Built to be clean and lightweight, Obsidian gives you a stable, straightforward server setup that is easy to manage.

---

## Roadmap

* [x] **Phase 1: Core Foundation**
  * Automated setup for the server and required files.
  * Easy support for adding your own mods and configurations.
  * Lightweight, minimal footprint out of the box.
* [ ] **Phase 2: Flexible Settings**
  * Easily change the Minecraft version or server memory settings without rebuilding the container.
* [ ] **Phase 3: Better Monitoring**
  * Built-in tools to track server health and performance metrics.
* [ ] **Phase 4: Remote Management**
  * A simple web interface to control the server and run commands remotely.
